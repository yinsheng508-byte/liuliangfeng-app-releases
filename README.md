## 怎么安装

1. 下载并双击打开 `.dmg` 安装包。
2. 将软件图标拖入「应用程序」。
3. 在「应用程序」中打开软件。

升级时先退出旧版，再拖入新版；出现提示时选择「替换」，不需要先卸载。

## 苹果首次打开提示无法验证，怎么办？

如果提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”：

1. 先尝试打开一次软件，再打开「系统设置 → 隐私与安全性」。
2. 向下滚动，找到该软件的拦截提示，点击「仍要打开」。
3. 按系统提示输入 Mac 密码或使用触控 ID，再点击「打开」。

如果提示“已损坏”或仍无法打开，请先重新下载安装包；仍有问题时，将系统版本和完整提示发给软件提供方处理。
